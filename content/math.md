# matrix
<span style="font-size: 40px;">you multiply whichever row of the first matrix, with each column of the second matrix.</span>
https://www.mathsisfun.com/algebra/matrix-multiplying.html
order matters. AB does not equal BA
Addition only works if the matrices are identical in shape. Must be equal amount of rows and columns. Addition is simple, you just add the ones in the same position. Multiplication, however...
Starting off simple. Number times Matrix equals times in every position. Same case when flipped. This is an exception where AB equals BA.
Now, when multiplying multiple matrices.
To show how many rows and columns a matrix has we often write rows×columns. Row goes from left to right, Column goes up to down.
The number of columns of the 1st matrix must equal the number of rows of the 2nd matrix. And the result will have the same number of rows as the 1st matrix, and the same number of columns as the 2nd matrix.
General rule for that is m $\times$ n x n $\times$ p = m $\times$ p
If you look at matrices as rectangles, the second matrice has to have the same height as the first matrices length.

			One term in denominator
				Multiply top and bottom by that radical to rationalize

				Multiply top and bottom by the conjugate (middle sign flipped)
		Adding or subtracting radicals
			Simplify each radical by pulling out perfect powers
			Combine matching radical terms
		Multiplying radicals
			Multiply out terms using distribution or FOIL
			Simplify any remaining radicals
	Rational expressions
		Complex fraction with mini-fractions inside
			Find the common denominator of all mini-fractions
			Multiply the entire top and bottom by that common denominator
		Single fraction to simplify
			Factor top and bottom completely
			Cancel identical factors
		Adding or subtracting fractions
			Factor the denominators
			Convert each fraction to a common denominator
			Combine numerators over that common denominator
			Factor the result to cancel remaining terms
		Multiplying or dividing fractions

			Factor every numerator and denominator completely
			Cancel common factors between top and bottom
